# 草料二维码

把日常工作，交给一句话。

连接草料账号，让 DeepSeek 帮你创建二维码、整理表单记录、分析巡检数据。

## 开始使用

1. 在 Harness 的“插件”页面添加并启用草料二维码插件。
2. 打开侧栏“草料二维码”，点击“连接草料账号”。
3. 在自动打开的草料授权页面登录并选择组织；若页面未打开，可点击“重新打开授权页面”。
4. 连接成功后，新建会话，告诉 DeepSeek 你想完成什么。

## 试着这样说

- 🟩 **快速建码**：帮我设计一个设备档案二维码，先给我看看方案。
- 📋 **表单与记录**：帮我查看最近的表单记录，整理出需要关注的信息。
- 🔍 **巡检与分析**：帮我分析本月巡检记录，总结异常情况和待跟进事项。

你可以继续补充需求，让 DeepSeek 按你的要求调整方案。
具体可用功能由所选组织的权限和套餐决定。

## 由你掌握连接

通过草料登录页面授权，无需填写 API Key。连接后可在当前 Harness 的会话中使用。
你可以随时在插件页面断开连接，或前往草料账号管理页面撤销授权。

了解更多：[草料二维码](https://cli.im/)
